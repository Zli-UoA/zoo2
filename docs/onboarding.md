# 初期ツアー

Web版ではログイン後、そのブラウザーで初めて使うアカウントに6ステップの案内を表示する。
チャンネル、投稿とスレッド、通知、Slack連携、設定を案内する。ナビゲーションのコンパスボタンからいつでも最初から再表示できる。

完了・スキップ・閉じる・Escapeはいずれも表示済みとして扱う。
状態はlocalStorageの `zoo:onboarding:v1:<ユーザーID>` に保存し、端末間では同期しない。
ストレージが使えない場合も閉じる操作は可能だが、再読み込みすると再表示する。
既存ユーザーにも導入後の初回起動時に表示する。APIや追加の通信は不要。

Webの画面操作を案内する任意の機能のため、Android・iOS・TUIには追加しない。
TUIのキー操作は既存のヘルプを引き続き使用する。Reactを共有するデスクトップ版には同じ案内が表示される。

Storybookの Features/Onboarding/Tour で初回、完了と再表示、スキップ、狭幅の表示を確認できる。

Slack連携のステップでは、既存のアカウント紐付け・自分で作った非公開チャンネルの取り込みを説明する。「Slack連携を設定」を選ぶとツアーを閉じ、設定のSlack連携タブへ移る。OAuth認可は既存の設定画面から利用者が開始する。
