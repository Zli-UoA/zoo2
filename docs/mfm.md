# MFM 対応表

MFM は `mfm-js@0.28.0` の全 AST 構文に対応しています。
関数と引数は 2026-10-25 に確認した Misskey develop の
[MFM_TAGS / MFM_PARAMS](https://github.com/misskey-dev/misskey/blob/develop/packages/frontend-shared/js/const.ts)
および [描画仕様](https://github.com/misskey-dev/misskey/blob/develop/packages/frontend-shared/js/mfm-renderer.ts)
を基準にしています。上流の描画コード・CSS は流用していません。
将来追加される未知の関数は原文表示します。

## 構文

| 構文 | 表示・操作 |
| --- | --- |
| 通常テキスト・Unicode 絵文字 | エスケープして表示。既存の URL・ローカルメンション装飾を維持 |
| `:shortcode:` | GitHub 絵文字コードを Unicode に変換。登録されたカスタム絵文字を優先 |
| `# 見出し`〜`###### 見出し` | Zoo拡張。行頭の半角 `#` と空白で6段階の見出し。太字・リンクなども使用可能。コード・plain・引用内は対象外 |
| `**bold**` / `<b>`、`<i>`、`~~strike~~`、`<small>` | 太字・斜体・取り消し線・小文字 |
| インラインコード・コードブロック | コード表示。言語指定時は highlight.js common 同梱言語を色付け。その他もコードを表示 |
| `>` 引用、`<center>` | 引用・中央寄せ |
| URL、`[label](https://...)`、`?[label](https://...)` | 安全な外部リンクとして別タブで開く。ただし、開いているアプリ自身のチャンネル・メッセージへのリンク（同じ origin の `/channels/<ID>`、`?message=` / `?thread=` 付きを含む）は、新しいタブを作らず同じタブでアプリ内を移動する（Ctrl・⌘・Shift・Alt を押したクリックや中クリックは、ブラウザー既定の別タブ・別ウィンドウ）。silent もリンクとして表示（もともとプレビュー取得なし）。行き先が分かるときの短い表示と埋め込みは、下の「チャンネル・メッセージのリンクの表示」 |
| `@name`、`@name@host` | ローカルはプロフィールアイコンと表示名を添えたメンション装飾（アイコン付きでは表示上の `@` を省略し、未解決名や `@channel` / `@here` には残す）。リモートはホストのプロフィールへのリンク |
| `#hashtag` | 同名の既存チャンネルへのリンク。名前の完全一致で判定し、未登録・削除済みはテキスト表示。チャンネル一覧の同期後に反映 |
| `query 検索` / `query Search` | Google の検索結果を別タブで開く。自動通信なし |
| `\(formula\)`、`\[formula\]` | KaTeX によるインライン・ブロック数式。フォントも自前配信 |
| `<plain>...</plain>` | 装飾・リンク化せず内容を表示 |

閲覧者本人宛ての `@name`、`@channel`、`@here` を含むメッセージは、そのメッセージ行の領域に薄い黄色の背景と左端のアクセントを表示します。投稿者が本人の場合も強調し、ホバーやフォーカス中も黄色の背景を保ちます。閲覧者が分からない通知や、参加していないチャンネルでは行を強調しません。

## チャンネル・メッセージのリンクの表示

本文に書いた、開いているアプリ自身のチャンネル・メッセージへのリンク（同じ origin の `/channels/<ID>`、`?message=` / `?thread=` 付きを含む）は、行き先が分かるとき、URL の代わりに短く表示し、投稿の下に埋め込みカードを出します。URL の文字そのものを書いたリンクだけが対象で、`[文字](URL)` の文字は書き換えません（カードは出します）。検索語を強調している間も、URL の文字は書き換えません。

| リンク | 本文中の表示 | 埋め込みカード |
| --- | --- | --- |
| メッセージ | 💬 のアイコンと「○○さん: #チャンネル名」（英語などは「Name: #channel」） | 投稿者のアイコン・名前、日時、`#チャンネル名`、本文（装飾・リンクを外した文字、3 行まで）。返信は `#チャンネル名 内のスレッド`。本文がなく添付だけなら「添付ファイル N 件」。コメントのない転送（引用）は、通知と同じ「メッセージを転送しました」（転送元は展開しない） |
| チャンネル | 「#チャンネル名」 | チャンネル名と説明。非公開・暗号化のチャンネルはその旨 |
| 暗号化チャンネルのメッセージ | 同上 | 本文は出さず、「このメッセージは暗号化されています」と書く。投稿者・日時・チャンネル名は本文ではないので出す。サーバーが `encrypted = false` を配っても、以前に暗号化と見たチャンネル（`localStorage` と暗号ストアの記録）・`edm:` の名前・暗号文のある行（対象の行か、この端末が読み込み済みの同じチャンネルの行）は、暗号化として扱う。暗号ストアを開いて確かめ終わるまでは、本文を出さず枠にする（このタブで開けない状態では、ほかの記録で判定して表示する。[docs/e2ee.md](e2ee.md) の「機能ごとの扱い」） |
| 連携カード・部品・App のブロックの投稿 | 同上 | チャンネルでは `content` の代わりにそれらを描く投稿なので、`content` は出さず、「Appのメッセージ」と書く |
| DM | 「ダイレクトメッセージ」（内部の名前 `dm:…` は出さない） | 同上 |

- カードはどこを押しても、同じタブでそのメッセージ・チャンネルへ移動します（本文中のリンクと同じく、Ctrl・⌘・Shift・Alt を押したクリックはブラウザー既定の動作）。`?thread=` だけのリンクはスレッドの親のメッセージを指します。
- 行き先が**見られない**ときは、カードを「メッセージを表示できません」（チャンネルのリンクは「チャンネルを表示できません」）にします。存在しない、削除済み、非公開で自分が参加していない、はどれも同じ表示で、理由・チャンネル名・本文は出しません。本文中のリンクは URL のまま残し、カードは押しても移動しません。見られるチャンネルかどうかは、サーバーが配るチャンネルの一覧（公開チャンネルと、自分が参加している非公開チャンネル・DM）で判定します。表示の都合の判定で、権限はサーバー側の Shape が守ります。
- チャンネルの一覧の同期が終わるまで、メッセージを取得している間は、「表示できません」と決めず、カードの枠（読み上げには「リンク先を読み込み中」）だけを置きます。リンク先のメッセージの取得（と、暗号化かどうかの確認）が、始めてから10秒たっても終わらないとき（画面から離れた間も数え、離れて戻っても枠に戻しません）は、枠をやめて「リンク先を読み込めませんでした」と書きます（見られない場合とは区別します。あとで取得できれば内容に切り替わります）。再試行されない失敗（認証の期限切れ、権限の不足などの 4xx）は、10 秒を待たずに同じ表示にします。この失敗は、リンクを出し直すだけでは取り直しません。ページを再読み込みするか、そのチャンネルの投稿を使う表示（リンク・チャンネル画面）がすべてなくなって 5 分たったあとの表示で取り直します（[request-design.md](request-design.md) の「メッセージリンクの埋め込み」）。チャンネルの一覧の同期を待っている間は、10秒を超えても枠のままです。
- カードも本文中の短い表示も、画面の近くに来てから取得し（チャットの投稿・スレッド・キャッチアップ・Home など）、一度取得したリンク先は、画面から離れても表示を保ちます（同じ要素が別のリンクに使い回されたときは、新しいリンク先を、近くに来るまで取得しません）。
- 転送（引用）のカードの本文に書いたリンクも同じ扱いです。転送の確認ダイアログのプレビューは、短い表示だけで、埋め込みカードは出しません。
- チャンネルの一覧を持つ画面（アプリのシェル）では、このリンクを Summaly に送りません。自分のデータ（`messages` Shape）から取るので、外部のサービスには URL もメッセージも見えません。
- チャンネルの一覧を持たない画面（公開プロフィールなど）では、行き先が見られるかを判定できないので、短い表示も埋め込みも出さず、今までどおり URL のまま表示します。投稿の下のカードも、外部の URL と同じ Summaly のカードのままです（[link-previews.md](link-previews.md) の「例外」）。

Android（`frontend-compose`）も、上の表と同じ内容を出します。本文中の短い表示は URL の文字そのものを書いたリンクだけで（`[文字](URL)` の文字は書き換えず、検索語の強調中も書き換えません）、埋め込みカードは投稿の下に出します。次の点は Web と違います。

- 接続先（API のベース URL）と同じ origin の `/channels/<ID>` を、このアプリのリンクとして扱います。押すと、ブラウザーを開かずにアプリ内で移動し、返信と `?thread=` のリンクはスレッドを開きます。見られない行き先でも、本文中の URL を押すとアプリ内で移動します。
- 投稿者のアイコンは、タイムラインと同じく名前の頭文字です。日時は検索結果と同じ「月/日 時:分」（今年でなければ年も付ける）です。
- 画面の近くの行だけを作る一覧（`LazyColumn`）で、行が作られてから行き先を取得します。取得は [request-design.md](request-design.md) の「メッセージリンクの埋め込み」のとおりです。取得するのは 1 つの投稿につき先頭 3 件のメッセージ（埋め込みの対象を含む）まで、同時に取得するチャンネルは 8 までです。転送（引用）のカードの本文に書いたリンクは、Web と同じく短くし、投稿の本文とは別に先頭 3 件まで取得します。
- メッセージの ID（UUID）の形でない `?message=` / `?thread=` は取得せず、見られない行き先と同じ表示にします。
- 暗号文のある行を一度でも読み込んだチャンネルは、購読を閉じたあとも、セッションの間は暗号化として扱います。
- 認証や権限の失敗（429 を除く 4xx）では、前に取得できた内容も出しません。5xx やオフラインで取り直している間は、前の内容を出します。
- サーバーのエラーなどで 1 件の取得の失敗が続くときは、一度打ち切って間隔を空けて取り直し、同じチャンネルのほかの取得と、表示した行の編集・削除の受け取りを続けます。
- 画面が非表示の間も、リンクを出している行が残っていれば、ほかの Shape の同期と同じく購読を保ちます（Summaly の取得のようには止めません）。
- 本文の URL は、Web と同じく ASCII の URL の文字と対応する括弧までです。日本語や全角の記号が続くと、そこで終わります（外部のリンクとそのカードも同じです）。`[文字](URL)` は、押して開く行き先だけをカードの対象にします（行き先の切り方は、本文のリンクと同じで、空白を含まず丸括弧を対にした範囲です）。`[文字](URL)` の解釈は Android の今までのままで、Web（ASCII の URL の文字だけを行き先にする）とそろえていません。非 ASCII の文字を含む行き先などは、Web ではリンクになりません。
- 連携カードの説明や項目の中のリンクは、今までどおりです（短くせず、埋め込みません）。

TUI（`tui`）も、同じ内容をテキストで出します。判定と要約は `client-types` の `links` にあります。次の点は Web と違います。

- 接続先（`api_base_url`）と同じ origin の `/channels/<ID>` を、このアプリのリンクとして扱います。
- 本文中の短い表示は「💬 ○○さん: #チャンネル名」で、埋め込みはメッセージの下に `┃` の線を付けた行です。本文の要約は折り返して 3 行まで、チャンネルの説明は 2 行までです。
- 移動はキー操作です。メッセージを選んで `o` を押すと開きます。リンクがいくつもあれば、選ぶ画面を出します。見られない行き先は開かず、理由を区別しない同じ表示を出します。
- 書きかけの返信があるときは、その送り先が変わるリンク（別のチャンネル、タイムライン、別のスレッド）は開きません。
- 開いた行は、チャンネルの同期がそろった時点で確かめます。それまで、実際の親が分からないスレッドには書き込めません（返信の入力と送信、参加 `J`・退出 `L`、再開 `u`。スレッドの中で選ぶものを動かしても同じです）。あとから別の行き先と分かっても、入力中や書きかけの返信があるときは、表示を切り替えません。切り替えずに残るスレッドが実際にはスレッドでなければ閉じます（そこへの返信を書いている間は閉じません）。確かめる前に同期が停止したら仮の表示をやめるので、開き直します。
- 埋め込みと移動の行き先は、本文の表示でリンクになる部分の行き先です。`~~` などの装飾の記号は含めず、`[文字](URL)` の行き先は日本語などがあっても切りません。ただし、`)` の直前のほかに空白があるものや、次のリンクの `](` を含むものは `[文字](URL)` にせず（閉じ忘れたリンクが後ろの本文を消さないように）、書いた URL を通常のリンクにします。コードと `<plain>`（行をまたぐものを含み、中の ```` ``` ```` の行も文字とします）の中は、対象にしません。本文の表示も同じ区切りで、行をまたぐ `<plain>` の中を文字のまま出し、終わったあとは通常の表示に戻します（デスクトップ版も同じ解析を使います）。
- 開いているチャンネルのリンク先は、そのチャンネルの同期を待ちます。待ち始めて 10 秒たつか、同期が停止したら「リンク先を読み込めませんでした」と書きます。停止したあとは、権限を失ったかもしれないので、届いていた行も出しません。
- 認証や権限の失敗（429 を除く 4xx）では、そのチャンネルで前に取得できた内容も出しません。5xx やオフラインで取り直している間は、前の内容を出します。
- 描画した範囲と前後の半画面にあるメッセージのリンク先だけを取得します。1 つの投稿から取得するのは先頭 3 件のメッセージ（埋め込みの対象を含む）までで、超えた分は、すでに分かっていなければ URL のまま表示します（`o` で選ぶ画面に出したリンク先は取得します）。同時に取得するリンク先のチャンネルは 8 までで、超えた分は「リンク先を読み込めませんでした」と書きます。

デスクトップ版（`desktop-tauri/`）の最小限の画面（`desktop_ui=leptos`）も同じ内容を出します。既定の `remote` は Web 版の画面です。判定は TUI と同じ `client-types` の `links` と `link_store` です。次の点は Web と違います。

- 接続先（`api_base_url`）と同じ origin の `/channels/<ID>` を、このアプリのリンクとして扱います。部品の文字にあるリンクも、アプリ内で開きます（短い表示と埋め込みは本文だけです）。
- 埋め込みに投稿者のアイコンは出しません（この画面の投稿の見出しも名前だけです）。
- クリックは、修飾キーを押していてもアプリ内で移動します。メッセージはタイムラインのその行へ送って強調します。この画面はスレッドを開けないので、返信は親のメッセージへ送り、その旨を知らせます。一覧にないチャンネル（未参加の公開チャンネルなど）は、上に名前を出して開きます。
- 見られない行き先は開かず、理由を区別しない知らせを出します。知らせと、読み込み中・失敗・見られない枠は、`role="status"` の領域に出します。
- アーカイブ済みのチャンネルをリンクで開いたときは、入力欄の代わりに、投稿できないことを書きます。
- 画面の近く（見える範囲と前後の半画面）にある投稿のリンク先だけを取得します。取得する数の上限（1 投稿につき先頭 3 件のメッセージ、同時に 8 チャンネル）は TUI と同じです。

メッセージリンク（`?message=`）、通知、検索結果から開いた行は、スクロールしたあと、その行の領域に青い背景と左端のアクセントを重ねて強調します。強調は 2.5 秒で、はじめの 0.5 秒に 3 回点滅し、そのあと 1.5 秒点灯を保ち、最後の 0.5 秒でフェードアウトします。メンションの強調がある行にも同じ強調を重ね、フェードアウトのあとはメンションの強調だけが残ります。表示中の対象へのリンクをもう一度押すと、行へ戻って最初から再生します。OS の「視覚効果を減らす」設定では点滅せず、2.0 秒点灯してから 0.5 秒でフェードアウトします。色は `styles.css` の `--message-target` で、ライト・ダークの各テーマに設定できます。

## 関数

基本形は `$[name.arg=value,flag 本文]`。すべて入れ子にできます。

| 関数 | 対応引数 |
| --- | --- |
| `tada`、`jelly`、`twitch`、`shake`、`jump`、`bounce` | `speed`、`delay` |
| `spin` | `speed`、`delay`、`left`、`alternate`、`x`、`y` |
| `flip` | `h`、`v`。省略時は水平反転 |
| `x2`、`x3`、`x4` | なし（文字を拡大） |
| `scale`、`position` | `x`、`y` |
| `fg`、`bg` | `color`（3/4/6/8桁の16進数、`#`なし） |
| `border` | `width`、`style`、`color`、`radius`、`noclip` |
| `font` | `serif`、`monospace`、`cursive`、`fantasy`、`emoji`、`math` |
| `blur` | なし。ホバーまたはキーボードフォーカスで解除 |
| `rainbow` | `speed`、`delay` |
| `sparkle` | なし（装飾用の星を点滅） |
| `rotate` | `deg` |
| `ruby` | なし。`$[ruby 漢字 かんじ]`。装飾した親文字にも対応 |
| `unixtime` | なし。本文の Unix 秒を端末のタイムゾーン・ロケールで表示（夏時間に対応）。ツールチップも同じ日時を表示し、`datetime` 属性は元の時点を UTC ISO 形式で保持 |
| `clickable`（上流 renderer 拡張） | `ev`。キーボード操作可能なボタン。`mfm-click` DOM イベント（detail は ev）を発行。コンポーネント利用側は `onClickEvent` で受け取り可能 |

## 入力補完

通常投稿・スレッド返信の入力欄で `#` を入力すると、閲覧可能な通常チャンネルを名前で絞り込んで補完できます。DMと削除済みチャンネルは候補に含めません。`# 見出し` やURL・コード内は補完しません。`/` は本文の先頭で、そのチャンネルに導入済みのAppコマンドを補完します。

通常投稿・スレッド返信の入力欄で `$` を打つと、MFM 関数名と説明の候補を表示します。
`$je` や `$[je` のように続けると関数名の前方一致で絞り込めます。
上下キーで候補を選び、Enter / Tab またはクリック・タップで挿入します。
例: `jelly` を選ぶと `$[jelly ]` が挿入され、括弧の中から本文を入力できます。
フォントや色などは編集可能な引数の例も挿入します。Esc で候補を閉じます。
IME 変換中も候補を表示します。半角の `$` では関数名、半角の `@` ではユーザー名・日本語を含む表示名で絞り込めます。
変換中の Enter・上下キー・Tab・Esc は IME の操作を優先し、候補の挿入や送信はしません。
コード内・URL 内・エスケープした `\$` では MFM 補完しません。

## カスタム絵文字

`frontend/public/mfm-emojis.json` に `{"party": "/emoji/party.webp"}` のように
名前と同一オリジンの画像パスを登録し、対応画像を `public` 配下に置きます。
本文の `:party:` が画像になります。未登録名は `:party:` のまま表示します。
登録内容はセッション内で一度取得します。変更後はページを再読み込みしてください。
外部サーバーの絵文字を自動取得する機能はありません。
画像の権利・ライセンス表記は追加した画像に合わせて更新してください。

## 入力制限とアクセシビリティ

- 動きは OS の `prefers-reduced-motion` で停止します（カスタム画像自体の GIF 等は対象外）。
- `speed` / `delay` は `s` と `ms` に対応。周期は 0.5秒〜24時間、遅延は ±24時間に制限します。
- 入れ子は20段、文字サイズと scale を合わせた累積拡大率は8倍まで（縮小で上限を緩めません）。scale は各軸 ±5、position は ±2em、rotate は ±36000度まで。
- 通常投稿・スレッド返信とも、変形やアニメーションが本文の領域を越えた部分は描画・クリック判定を切り取ります。隣の投稿や操作ボタンには重なりません。
- 枠線は幅0〜100px、角丸0〜1000px。数式はマクロ展開回数1000、サイズ20まで。
- 数式の任意 HTML・外部 URL 拡張、任意 CSS、JavaScript リンク、本文由来のスクリプト実行を許可しません。
- 数式の誤入力は元の式をエラー表示します。未知のコード言語は通常コードとして表示します。
- 編集内容は元の MFM を保持します。通知や検索の抜粋は従来どおりテキスト表示です。
