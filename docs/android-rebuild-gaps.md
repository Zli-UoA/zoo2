## 確認済みの範囲

main の `01e3f217` を取り込んだ時点で、デバッグAPKのビルドとAndroidアプリのユニットテスト197件、通話コントローラーとComposeプレビューのテストが通過した。バックエンドのPushテストは18件が通過し、PostgreSQLを使う2件は対象外。Webの入力欄テスト4件と `make tui-check` も通過した。

Androidでは、全文検索APIを使う画面と、ホームの投稿作成からチャンネルへ連携投稿する操作は未実装。
