# Android 作り直しの実装状況

[合意デザインのサンプル](android-design-samples.md)と[Compose キャプチャ](android-rebuild-samples.md)を参照。キャプチャは Robolectric 上で表示用データを使って描画している。

| 項目 | Android で接続した操作 | 残る作業 |
| --- | --- | --- |
| 操作体験 | ホーム・会話のヘッダー開閉、左スワイプの追従と確定、長押しシート、触覚とスワイプ設定の保存 | 端末で戻るジェスチャー・縦スクロールとの競合を確認 |
| スレッド | スライド遷移、端末の動きを減らす設定、会話のリスト位置・下書きの保持 | 参加・退出・再開・参加者管理 |
| 会話 | チャンネル投稿とスレッド返信、添付、暗号化された本文の復号、書式と絵文字の選択 | メッセージ編集・削除・リアクション・メンション補完・リンクのプレビュー。書式適用時の選択範囲の保持 |
| ホーム | タイムライン切替・投稿・返信、投稿内の最近の写真と OS ピッカー、画像添付 | 投稿編集・削除・リアクション・再投稿・プロフィール・フォロー・検索、公開範囲の詳細 |
| 通知 | 可視範囲での自動既読、一覧末尾での追加取得、チャンネル投稿を開く導線、画像付き OS 通知の既存配信処理 | 端末での配信と遷移の確認、連合通知の遷移とフォローリクエストへの応答 |
| 認証 | ブラウザ PKCE、App Links、セッション復元を新画面に接続 | 接続環境でブラウザ認証からの復帰を確認 |
| 通話 | 着信・応答・終了・ミュート・スピーカー・DM 発信と受信設定 | 端末間の着信、バックグラウンド復帰、音声ルーティングを確認 |
| チャンネル | 一覧、検索、作成、名前・説明の編集、参加・退出、アーカイブ、DM 作成、権限付きメンバー追加・削除 | ピン留め、グループ DM、非公開チャンネル等の作成・詳細設定、Web と権限の差分確認 |
| Bubble・一般設定 | Bubble のリアルタイム入力、外観・操作・言語選択・検索エンジン・OS 通知設定・ログアウト | Bubble の参加者、E2EE の端末・鍵バックアップの管理画面、画面文言の翻訳 |
