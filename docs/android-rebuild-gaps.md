# Android 作り直しの合意事項と現状

[合意デザインのサンプル](android-design-samples.md)と、[作り直しブランチの Compose キャプチャ](android-rebuild-samples.md)を照合した。画面は架空データで描画できる。アプリの起動、セッション、各画面の操作をつなぐ実装は作業中。

| 合意事項 | 現状 |
| --- | --- |
| 会話ヘッダーからチャンネル設定を開く | 名前・説明・右向きの矢印を一つの操作領域にした。設定画面までの遷移を Compose テストの画面状態で確認。チャンネルの設定項目・権限と本体の導線は未接続。名前16sp、説明13spの通常ウェイトで1行省略。 |
| 5つのトップだけに下部タブを表示する | 新UIに反映。起動・画面履歴との接続は作業中。 |
| チャンネル一覧と設定に区切り線を置かない | 新UIに反映。チャンネル一覧は名前のみ。チャンネル名の未読は太さで示し、個人DMのユーザー名は500で表示する。会話とスレッドも余白で区切る。 |
| 読み進めるとヘッダーを隠し、逆方向で戻す | スクロールとの連動は未実装。 |
| 左スワイプ・長押し・触覚 | 長押しの操作シートを実装。ホーム投稿を開く、チャンネル投稿のスレッドを開く、本文をコピーできる。スワイプ確定時の触覚を設定状態で切り替える。スワイプ中のメッセージの追従と実機での設定接続は残っている。 |
| スレッドに入る・戻るアニメーション | 会話との往復に240msのスライドを実装。動きを減らす設定が有効なら即時切り替え。会話のスクロール状態は画面を離れても保持できるようにした。 |
| 会話入力と書式 | 待機・入力中・全画面と、指に追従する上端のつまみがある。入力欄の下端にアイコンを置いた。書式・絵文字・添付の操作先と入力選択の保持、端末の IME での確認は残っている。 |
| ホーム投稿の写真選択 | 投稿内の最近の写真と OS ピッカーの入口がある。端末の写真・アクセス許可・添付とプレビューへの接続は未完了。 |
| 通知を表示したら自動既読 | 表示を契機に既読イベントを発行する。既存APIへのアダプターはある。本体への接続、通知フィルター・画像付きプレビュー・OS 通知の操作は未完了。 |
| Device Code を使わないブラウザログイン | ログイン・復元中の表示がある。起動時の復元、ブラウザ認証と App Links からの復帰は新UIに未接続。 |
| 通話のライト・ダークと内容幅のボタン | 着信・通話中の描画がある。OS の着信と接続中の通話操作は新UIに未接続。 |
| 設定・管理・プロフィールを含む全画面 | 子画面の共通描画はある。個別設定、チャンネル・メンバー管理、プロフィール・検索の一連の操作は未接続か未実装。 |
